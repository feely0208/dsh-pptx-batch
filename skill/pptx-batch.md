# PPT 批量处理

**一句话**：整目录的 PPT 一次处理完 —— 批量填模板占位符、按形状名换图片、提取每页文本、看页数/形状数/图片数。只读输入，产物单独输出，不覆盖原文件。

## 什么时候用

用户说这些话时用：

- 「这套模板有 30 份按客户发，帮我把 `{{客户}}`、`{{金额}}` 填上」
- 「每份 PPT 右上角那个 Logo 都要换成新版，形状名是 Logo」
- 「把这几份 pptx 每页的文字导成 txt，我要核对内容」
- 「看看这批 PPT 各有多少页、多少张图」
- 用户给了一个装了很多 `.pptx` 的目录，要求批量处理其中文字或图片

## 怎么调用

```bash
<cli 路径> --help
```

```bash
# 批量填占位符（--set key=value 可重复；替换幻灯片里的 {{key}}）
<cli 路径> fill --input <文件或目录> [--out <输出目录>] \
  --set 客户=客户甲 [--set 金额=128000] [--json]

# 按形状名换图片（形状名精确匹配，大小写敏感）
<cli 路径> replace-image --input <文件或目录> [--out <输出目录>] \
  --shape Logo --image <新图片文件> [--json]

# 提取每页文本到同名 .txt（标题 + 正文 + 表格 + 备注）
<cli 路径> extract-text --input <文件或目录> [--out <输出目录>] [--json]

# 页数 / 形状数 / 图片数
<cli 路径> info --input <文件或目录> [--json]

# 自造样例跑完整流程（不碰用户文件），先跑这个确认环境正常
<cli 路径> --demo
```

## 输出约定（要向用户说清）

- **不修改输入文件**；输出默认写到 `<输入目录>/_输出`，可用 `--out` 指定。
- 同名产物不覆盖：自动变成 `简报_1.pptx`、`简报_2.pptx`。
- 目录递归处理，跳过 `~$` 临时文件和 `_输出` 目录。
- 成功退出码 0；参数/输入错误退出码 2；缺依赖退出码 3；运行失败退出码 1。
- `--json` 输出结构化结果（每个文件的产物路径、替换次数、页数/形状数/图片数等）。
- `fill` 会把「填完之后还剩哪些 `{{...}}`」报在 `unfilled` 里 —— 用来抓模板里拼错的 key。
- `replace-image` 批量时，**没有该形状的文件原样带到输出目录**（JSON 里 `replaced: 0` + `skipped`），
  只有当整批都没有这个形状时才报错非 0 退出，避免打错一个字就把整批弄失败。

## 边界（必须向用户说清）

- 只支持 `.pptx`；`.ppt` 老格式、`.pptm`、加密文档不支持，需先另存为 `.pptx`。
- `fill` 覆盖**文本框、占位符、表格单元格、组合形状里的文本框**；
  **不处理**图表文字、SmartArt 文字、图片里的文字、批注、母版/版式上的文字，也不跨段落匹配。
- `fill` 的匹配是**字面匹配**（`{{key}}`，key 大小写敏感，允许 `{{  key  }}` 这种空格），不支持正则；
  同一个 key 一次只能给一个值。
- **格式尽量保留但不保证 100%**：占位符整段在一个 run 里时，该 run 的字体/字号/颜色完全不动；
  跨多个 run 的匹配会把这几段文字并到起始 run 的格式上，中间 run 的局部格式会丢。
  重要模板先跑一份对比，再批量用。
- `replace-image` 只换**图片内容**：形状的位置、尺寸、名称都不变。新图比例和原图不同时会被**拉伸**，
  裁剪（crop）设置也沿用原来的；不支持按图片内容或页码挑选，只按形状名，同名形状会全部替换。
- `extract-text` 提取标题、正文、表格、备注页文字；不提取图表数据、SmartArt、页码和母版文字，
  图片只留位置不留文字（没有 OCR）。
- `info` 的「形状数」是每页顶层形状数之和（组合形状算 1 个，其内部形状不计入），
  「图片数」包含组合形状里的图片。
- 缺 `python3` 或 `python-pptx` 时会明确打印安装命令（`python3 -m pip install python-pptx`），不会静默失败。
- 不联网、不上传文件，全部在本机由 python-pptx 处理。
